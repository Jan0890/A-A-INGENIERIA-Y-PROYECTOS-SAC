# A&A Ingeniería y Proyectos SAC 🏗️⚡

Sitio web corporativo para **A&A Ingeniería y Proyectos SAC**, una empresa dedicada a soluciones integrales en ingeniería eléctrica, civil y mantenimiento industrial.

## 🎯 Objetivo del Proyecto
Desarrollar una presencia digital optimizada, de bajo costo de mantenimiento y alta velocidad de carga, enfocada en la conversión directa a través de información clara y puntos de contacto accesibles.

## ✨ Características Principales
* **Navegación Intuitiva:** Secciones de Inicio, Nosotros, Servicios y Contacto integradas en una sola página (One-Page).
* **Diseño Adaptativo:** Visualización correcta en smartphones, tablets y desktops.
* **Optimización SEO:** Configuración de meta-etiquetas para mejorar la visibilidad en buscadores.
* **Componentes Dinámicos:** Carrusel de proyectos y servicios utilizando recursos ligeros.

## 🛠️ Tecnologías y Herramientas
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla).
* **Iconografía:** Font Awesome / Google Fonts.
* **Despliegue:** Vercel (Hosting gratuito y seguro con SSL).
* **Control de Versiones:** GitHub.
